# 1.1 Создание сайта стартап-проекта

Сайт стартап-проекта Boostaurant опубликован по адресу https://boostaurant.ru/. Доменное имя boostaurant.ru зарегистрировано у регистратора REG.RU; обслуживание зоны выполняется DNS-серверами регистратора.

Сайт размещён на выделенном виртуальном сервере (VPS) хостинг-провайдера Beget под управлением Ubuntu 24.04. Веб-сервер — Caddy; соединение защищено протоколом HTTPS с сертификатом Let's Encrypt, выпуск и продление которого выполняются веб-сервером автоматически.

Сайт выполнен как статический: страницы свёрстаны на HTML и CSS без использования конструкторов сайтов и серверной логики, поля ввода и формы сбора данных отсутствуют. Вёрстка адаптирована под мобильные устройства. Исходный код сайта хранится в репозитории проекта вместе с кодом платформы; публикация изменений на сервер выполняется сценарием развёртывания.

Сайт состоит из двух страниц.

**Главная страница** (https://boostaurant.ru/) описывает продукт для владельцев и управляющих ресторанами и содержит условия пилотного внедрения. Первый экран страницы приведён на рисунке 1.
