# SVD — как работает рекомендательная модель

## Задача

Есть таблица «клиент × блюдо», где значения — количество заказов. Большинство ячеек пустые: клиент заказал лишь часть меню. Задача — заполнить пропуски: угадать, какую оценку клиент поставил бы блюду, которое ещё не пробовал.

```
           Борщ  Стейк  Салат  Тирамису
Иван         3     ?      1       2
Мария        0     5      0       0
Петр         1     4      0       1
```

## Идея: карта вкусов

SVD находит скрытые оси — «направления вкусов». Каждый клиент и каждое блюдо получают координаты на этих осях.

```
         ^ "любит сытное"
         |
  Иван • |
  Петр • |
─────────┼─────────→ "любит лёгкое"
         |        • Мария
```

Чем ближе клиент и блюдо на этой карте — тем выше предсказанная оценка.

**Важно:** названия осей ("сытное", "лёгкое") никто не задаёт. Это математические направления без имён. Названия — только иллюстрация для понимания.

## Разложение: три части

```
A = U × Σ × Vᵀ
```

| Матрица | Что содержит | Пример |
|---------|-------------|--------|
| **U** | векторы клиентов | `Иван → [0.8, 0.2, 0.5, ...]` |
| **Σ** (Sigma) | сингулярные числа — вес каждой оси | `[45.2, 12.8, 3.1, ...]` |
| **Vᵀ** | векторы блюд | `Стейк → [0.9, 0.1, 0.3, ...]` |

Предсказание для пары (клиент, блюдо) = скалярное произведение их векторов с учётом весов Σ.

## Сингулярные числа

Один набор чисел на всю модель (не на каждое блюдо). Показывают важность каждой оси:
- Большое число → ось объясняет много паттернов заказов
- Маленькое число → ось почти ничего не объясняет, можно выбросить. Эта фича используется в алгоритмах сжатия изображений

## Сколько осей

Теоретически — min(клиентов, блюд). При 1000 клиентах и 50 блюдах — 50 осей. На практике оставляют 10–20 главных (с большими сингулярными числами), остальные выбрасывают — они только шум.

## Связь с собственными числами

Сингулярные числа матрицы A — это корни из собственных чисел (eigenvalues) матрицы AᵀA. SVD используют вместо eigendecomposition, потому что матрица заказов прямоугольная (клиентов ≠ блюд), а собственные числа есть только у квадратных матриц.

## Почему так называется

- **Decomposition** — разложение одной таблицы на три простые части
- **Singular Value** — сингулярные числа, мера важности каждой оси
