# K-means — кластеризация клиентов

## Задача

SVD отвечает на вопрос «что закажет *этот* клиент?». K-means отвечает на другой вопрос: **«на какие группы похожи клиенты?»**

В Boostaurant используется для cold-start: когда клиент новый и истории заказов нет, смотрим, что заказывают похожие клиенты из того же кластера.

## Идея: разбить точки на группы

Каждый клиент — точка в пространстве признаков. Признаки — оси координат:

```
^ средний чек
|
|        • Оля            ← кластер «дорогие, редкие»
|                  • Дима
|
|   • Саша  • Петя        ← кластер «дешёвые, частые»
|   • Вова
└─────────────────────→ частота визитов
```

K-means находит **K центров** (K задаём заранее) и распределяет каждую точку к ближайшему.

## Алгоритм: 3 шага по кругу

**Шаг 1.** Случайно бросаем K центров (centroid — центр кластера).

**Шаг 2.** Каждого клиента относим к ближайшему центру.

**Шаг 3.** Пересчитываем центр каждого кластера — как среднее всех точек в нём.

Повторяем Шаг 2 → Шаг 3 → ... пока центры перестанут двигаться. Обычно 10–50 итераций.

## Ключевые понятия

| Понятие | Что это |
|---------|---------|
| **K** | Количество кластеров — задаём вручную |
| **Признаки** | Оси, по которым измеряем клиентов (средний чек, частота визитов, loyalty tier) |
| **Centroid** | Центр кластера — среднее векторов всех клиентов внутри него |
| **Вектор клиента** | Набор его признаков: `[gold, 2500р, 3 визита/мес]` |

Вектор признаков есть у каждого **клиента**. У кластера есть только **центр** — среднее этих векторов.

## Trade-off при выборе K

**Большое K** → кластеры маленькие и однородные → клиенты внутри очень похожи, но данных мало → рекомендации узкие.

**Маленькое K** → кластеры большие → данных много → рекомендации усреднённые по очень разным людям.

Крайний случай K=1: все клиенты в одном кластере — вырождается в нечто похожее на popularity fallback, но реализован отдельно через SQL.

## Как используется в Boostaurant

Признаки берём из iiko (известны даже для нового клиента):
- уровень лояльности (bronze / silver / gold)
- давность регистрации
- средний чек (если есть хоть пара заказов)

```python
cluster_id = kmeans.predict(customer_features)
return popular_in_cluster(cluster_id, top_n=5)
```

Если данных нет вообще — крайний fallback: топ-5 по ресторану за 30 дней.

## Отличие от SVD

| | SVD | K-means |
|---|---|---|
| **Вопрос** | Что закажет *этот* клиент? | На какие *группы* похожи клиенты? |
| **Выход** | Оценка для каждой пары (клиент, блюдо) | Номер кластера для каждого клиента |
| **Для кого** | Клиентов с историей заказов | Новых клиентов (cold-start) |
